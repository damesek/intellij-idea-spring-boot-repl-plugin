# IntelliJ IDEA 2025.2 – ellenőrzött 0.13.1 kiadás

A 2025.2-es Community és Ultimate SDK letöltése sikerült. A teljes Gradle-build és a Plugin Verifier lefutott; mindkét 2025.2-es kiadás eredménye **Compatible**. Az aktuális, Gradle-lel készített telepítő: **`build/distributions/sb-repl-0.13.1.zip`**.

A telepítő azóta a kibővített PDF-súgóval újracsomagolva. Ennek külön ellenőrzése és aktuális SHA-256 értéke a [kézikönyv frissítési jelentésében](HELP_UI_0_13_1.md) található. Az alábbi teljes tesztkör és Plugin Verifier eredménye az eredeti, lent megadott hashű csomagra vonatkozik.

## Elvégzett javítások

- A kompatibilitási tartomány `241.0`–`252.*`. A Gradle és a helyi csomagoló közösen a `gradle.properties` beállításait olvassa.
- A Gradle-tesztekben az IntelliJ `PathClassLoader` osztálybetöltője elrejtette a JDK fordítószolgáltatását a JShell elől. A JShellt beágyazó három tesztosztály most külön, normál JVM-ben fut a `jshellIntegrationTest` feladattal. A többi plugin-teszt megtartotta az IntelliJ tesztkörnyezetét. A `test`, `check` és `buildPlugin` a külön tesztfeladatot is lefuttatja.
- A használt Gradle-plugin egy termék több SDK-verzióját a legújabbra vonta össze. A 2025.2-es és a korábbi IDE-k ezért külön verifier-futást kaptak. A `-PverifyPreviousIdes=true` választja a korábbi párost. A CI mindkettőt futtatja, külön jelentéskönyvtárakba, így az eredmények nem írják felül egymást.
- A plugin, agent és bridge kiadási verziója 0.13.1. A csomag megőrzi a Java-plugin függőségét és a megfelelő `runConfigurationExtension` regisztrációt.

A fordítási alap IC 2024.1.4 és Java 17, az újabb IDE-k külön kompatibilitásvizsgálatot kapnak. Ez követi a JetBrains több főverzió támogatására vonatkozó útmutatását. [JetBrains: buildszámok és több IDE-verzió támogatása](https://plugins.jetbrains.com/docs/intellij/build-number-ranges.html).

## Teljes Gradle-tesztkör

Helyi ellenőrzés: **2026-09-14**, a korábbi hálózati, fájlírási és socketkorlátozások nélkül.

| Tesztcsoport | Java 17 | Java 21 |
| --- | --- | --- |
| Plugin-tesztek az IntelliJ tesztkörnyezetében | 53 sikeres | 53 sikeres |
| JShell/plugin integráció normál JVM-ben | 11 sikeres | 11 sikeres |
| Runtime, agent, nagy snapshot és debugger | 104 sikeres | 104 sikeres |
| **Összesen** | **168 sikeres** | **168 sikeres** |

**336 sikeres teszt, 0 hiba, 0 kihagyás.** A valódi MCP HTTP-, hitelesített nREPL socket- és JDI debugger-integráció is lefutott. A Gradle-ben deklarált Spring Boot 3.5.6-os tesztfüggőségeket használó futás sikeres, beleértve a csomagolt agenttel induló Spring alkalmazást, a profilokat, a HotSwap/Trace működését és az executable Boot JAR osztályazonosságát.

A teljes Kotlin plugin, Java runtime, protokoll és bridge a Gradle-folyamatban fordult le. Az instrumentálás, a kereshető beállítások indexelése és a telepíthető ZIP csomagolása is sikeres.

## Csomag és bizonyítékok

A ZIP érvényes, 407 éles plugin-osztályt tartalmaz, Java 17-es bytecode-céllal. A plugin JAR, a közös protokoll és a kereshető beállítások indexe külön JAR-ban van. A beágyazott agent a Gradle által készített és tesztelt agenttel azonos; a magyar PDF a csomagban megtalálható.

- Telepítő: `build/distributions/sb-repl-0.13.1.zip`
- Ellenőrzőösszeg: `build/distributions/sb-repl-0.13.1.zip.sha256`
- Teszteredmények és csomagellenőrzés: `build/idea-2025-2/gradle-validation.json`
- Megőrzött Java 17/21 XML-jelentések: `build/idea-2025-2/gradle-reports-17` és `gradle-reports-21`
- Gradle-naplók: `build/idea-2025-2/gradle-verified-17.log` és `gradle-verified-21.log`
- Aktuális verifier-jelentések: `build/reports/pluginVerifier/2025.2` és `build/reports/pluginVerifier/previous`
- SDK-letöltési napló: `build/idea-2025-2/sdk-download.log`

A fenti teljes tesztkörrel és Plugin Verifierrel ellenőrzött, PDF-bővítés előtti ZIP SHA-256 értéke:

```text
95294c662ebce252de0d5908115b8e7c393bc8a1bff1ed94fdbed218107fa83a
```

A CI-ben is használt ellenőrzés:

```sh
./gradlew --no-daemon check buildPlugin -PtestJdk=17
./gradlew --no-daemon check buildPlugin -PtestJdk=21
./gradlew --no-daemon verifyPlugin -PtestJdk=21
./gradlew --no-daemon verifyPlugin -PtestJdk=21 -PverifyPreviousIdes=true
```

A bináris ellenőrzés és az automatizált tesztek nem fedik le a felhasználó saját projektjében, a teljes IntelliJ felületen végzett interaktív próbát. Ilyen kézi próbát ezen a körön nem végeztem.

## Telepítés

Másold át a **`sb-repl-0.13.1.zip`** fájlt. IntelliJ-ben: **Settings → Plugins → fogaskerék → Install Plugin from Disk**, majd indítsd újra az IDE-t. A plugin verziója **0.13.1**. A meglévő Spring Boot konfigurációban az **Enable Spring Boot REPL** opcióval indul a REPL; a profilok az **Active profiles** mezőben adhatók meg.
